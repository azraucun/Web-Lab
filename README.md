# Web-Lab 2 

This is my second assignment for the Web Programming lecture.

## Files Organization

- index.html - The main page with 6 boxes A-F.
- styleA.css - Version A. Boxes are vertical and centered. I used Flexbox here.
- styleB.css - Version B. Boxes A-E are in a row, box F is in the bottom right corner.


## Challenges

- Flexbox was confusing at first, especially 'justify-content' and 'align-items' with 'flex-direction: column'.
- My boxes were bigger than 100x150 because of padding and border. I fixed it with 'box-sizing: border-box'.
- In Version B the boxes went to the next line when the window was small. I used 'white-space: nowrap'.
- There was extra space between the boxes. I fixed it with 'font-size: 0' on the body.
